# CodeAtlas

Сервис, который скачивает и индексирует репозиторий, чтобы можно было быстро задавать вопросы о содержимом кода и получать ответы на естественном языке.

## Основная идея

- Клонируем Git-репозиторий.
- Разбиваем код на фрагменты и считаем эмбеддинги.
- Сохраняем индексы в векторное хранилище.
- Пользователь задаёт вопрос → находим релевантные фрагменты кода → отдаём ответ с пояснениями и ссылками на файлы.


## Установка и запуск (dev)

```bash
# установка зависимостей
make setup

# линт и типизация
make lint

# форматирование
make format
```
